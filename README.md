## Booking
- Field rentals & academy free sessions booked via embedded Square Appointments
- Field price cards link to Square field rental booking
- "Free Session" links go to Square academy booking

## SEO
- Local business schema (SportsActivityLocation) included for Google Maps/local results
- Open Graph + Twitter cards for social link previews
- Keywords target: Alafaya soccer academy, Orlando kids soccer, soccer field rental Orlando

## To update the live site
Re-upload changed files to GitHub repo → GitHub Pages auto-rebuilds in 1-2 min.
